# קוד המקור של המפה

`index.html` שבשורש המאגר נבנה מהקבצים כאן. **לא עורכים את `index.html` ישירות** — כל שינוי (תוכן או עיצוב) נעשה כאן ונבנה מחדש.

- `template.html` — מנוע התצוגה: HTML, CSS ו־JS. המקום `/*DATA*/` מתמלא בקבצי הנתונים.
- קבצי נתונים: `data.js` (מבדקים, מסגרת כללית, אזורים), `extras.js` (סרטונים, ראשי תיבות), `tx1.js`–`tx7.js` (כרטיסי מבדקים; `tx4.js` — גב תחתון ואגן, `tx5.js` — ירך ומפשעה, `tx6.js` — ברך, `tx7.js` — קרסול וכף רגל), `evguide.js` (מדריך הראיות), `found.js` (לשונית "עקרונות"), `tissue.js` (לשונית "רקמות").
- `parked-regional.js` — תוכן של שריר ספציפי שממתין לאזור שלו (למשל המסטרינג ← ירך). **לא נכנס לבנייה.** הכלל: נושא כללי על שריר ← "רקמות"; שריר ספציפי ← האזור שלו, תחת המפרק שהוא קשור אליו.
- חוזה עם העוזר הקליני (`app/kb-site.js` בענף `app`): שמות הליטרלים `T, GENERAL, REGIONS, FIVE_D, THREE_N, TEST_GEN, TX, TX2, TX3, TX4, TX5, TX6, TX7, FOUND, TISSUE` נשארים בתחילת שורה כ־`const NAME = {`.

## בנייה ובדיקה (משורש המאגר)

```
node src/build.js && python3 src/build-site.py     # בונה את index.html
cd src && npm install && node check3.js             # בדיקת תצוגה של כל כרטיסי המבדקים (jsdom)
```

## ענפים

- `old` — גיבוי: העיצוב הקיים, לפני אזור הגב התחתון והאגן.
- `l45` — העבודה על אזור הגב התחתון והאגן; מוזג ל־`main`.
- `new` — העיצוב החדש (בעבודה).
- `main` — מה שבאוויר. ממזגים אליו רק כשפלטון מבקש.
- `app` — העוזר הקליני (Thalamus). שינויי המפה שלו (קישורי עומק, סרגל לטאבלט, כפתור Back, פוקוס על ראשי תיבות) הועברו ל־`template.html`, חוץ מכפתור הקישור ל־`app/` — הוא נשאר רק בענף `app`.
